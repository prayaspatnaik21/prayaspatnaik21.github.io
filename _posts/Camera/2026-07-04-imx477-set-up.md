# About

I am setting up an Arducam Sony IMX477 camera with an NVIDIA Jetson Orin Nano Developer Kit. This post is my working setup log, including the hardware checks, software checks, and debugging notes needed to get the camera detected and streaming.

The setup has two major parts:

1. Hardware connection and cable orientation
2. Software installation, detection, and streaming tests

## Hardware Notes

Connecting the camera correctly is the most important part of the setup. A bad ribbon-cable connection can make the software look broken even when the driver is installed correctly.

When ordering the camera, Arducam provides different CSI ribbon cables:

1. 15-pin to 22-pin cable
2. 22-pin to 22-pin cable

For the Jetson Orin Nano Developer Kit, the white 22-pin to 22-pin cable is the one that fits both the camera and the Jetson CSI connector. The brown cable is commonly used with Raspberry Pi-style 15-pin connectors.

The most important cable detail:

> 1. On the Camera side , the shiny metal contacts on the ribbon cable should face toward the green circuit board of the camera module.
> 2. The above statement was recommended by Arducam and from the youtube tutorials.
> 3. It didn't work. 
> 4. The camera was not getting recognized by Jetson . It was not getting powered.
> 5. For some reason , the delivered Camera's CSI Connector was inverted , so the shiny metal contacts should face upward . 
> 6. I tried this because the recommended approach did not work for me. After multiple attempts, two lost days, and a few sacrificed hair strands, this was the path that finally helped me debug the issue.

On the Jetson side , push the ribbon fully into the CSI connector before locking the latch. This matters because a loose or reversed ribbon can still make the IMX4777 driver appear in the dmesg , 
but the sensor will not respond over I2C.In that case , linux will not create `/dev/video0`.

```bash
sudo apt update
```

```bash
sudo apt install v4l-utils gstreamer1.0-tools
```

### Install IMX477 Driver

From the camera scripts folder:

```bash
./install_full.sh -m imx477
```
Download the camera driver installation scripts from the [Arducam Jetson Native Camera Quick Start Guide](https://docs.arducam.com/Nvidia-Jetson-Camera/Native-Camera/Quick-Start-Guide/).

After installation, reboot:

```bash
sudo reboot
```

## Camera Detection

After reboot, check whether Linux created a video device:

```bash
ls /dev/video*
```

## I2C Checks

The driver tried to find the camera on I2C buses 9 and 10, so both buses were checked manually.

```bash
sudo i2cdetect -y -r 9
```

## Streaming Output

After the camera was detected, I used `nvarguscamerasrc` to stream the IMX477 output through GStreamer:

```bash
gst-launch-1.0 nvarguscamerasrc sensor-id=0 ! 'video/x-raw(memory:NVMM),width=4032,height=3040,framerate=21/1' ! nvvidconv ! xvimagesink
```
